# Сервис сокращения ссылок

Консольное приложение на Java 21: превращает длинный URL в короткий вида `clck.ru/3DZHeG`.
У каждой ссылки есть лимит переходов и время жизни.

## Что умеет

- создавать короткие ссылки (код уникален, поэтому один и тот же URL у разных пользователей даёт разные ссылки);
- считать переходы и блокировать ссылку, когда лимит исчерпан;
- удалять ссылки по истечении времени жизни (время задаётся в `config.properties`, а не пользователем);
- уведомлять владельца, когда лимит исчерпан или срок жизни истёк;
- определять пользователя по UUID без регистрации (UUID создаётся при первом `create` и сохраняется в файле `user.id`);
- разрешать менять лимит и удалять ссылку только её создателю;
- открывать исходный сайт в браузере (`Desktop.getDesktop().browse(...)`).

## Установка и запуск

Нужны JDK 21 и Maven. Других библиотек не требуется.

```bash
mvn clean package
java -jar target/link-shortener.jar
```

Запускать нужно из папки, где лежит `config.properties`.

## Команды

| Команда | Что делает |
|---|---|
| `create <url> [лимит]` | создать короткую ссылку |
| `open <ссылка>` | перейти по ссылке (откроется браузер) |
| `list` | показать мои ссылки |
| `limit <ссылка> <лимит>` | изменить лимит (только владелец) |
| `delete <ссылка>` | удалить ссылку (только владелец) |
| `notifications` | мои уведомления |
| `whoami` | показать мой UUID |
| `login <uuid>` | войти под другим UUID |
| `help`, `exit` | справка, выход |

Ссылку можно писать как `clck.ru/abc123`, `https://clck.ru/abc123` или просто `abc123`.

Пример:

```
> create https://www.baeldung.com/java-9-http-client 2
Ваш UUID (сохраните его): 0b5c...
Короткая ссылка: clck.ru/8kQdGw
Лимит переходов: 2, действует до 03.11.2026 13:57:12
> open clck.ru/8kQdGw
> open clck.ru/8kQdGw

[УВЕДОМЛЕНИЕ] Лимит переходов по ссылке clck.ru/8kQdGw исчерпан (2)
> open clck.ru/8kQdGw
Ошибка: Лимит переходов по ссылке clck.ru/8kQdGw исчерпан
```

## Настройки (`config.properties`)

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `short.domain` | `clck.ru` | домен в короткой ссылке |
| `short.code-length` | `6` | длина кода |
| `link.ttl-seconds` | `86400` | время жизни ссылки (сутки) |
| `link.default-limit` | `10` | лимит переходов по умолчанию |
| `link.max-limit` | `1000` | максимальный лимит |
| `cleanup.interval-seconds` | `5` | как часто проверять просроченные ссылки |

## Как устроено

- `Main` — консольный интерфейс и фоновая очистка просроченных ссылок;
- `LinkService` — вся логика (создание, переходы, лимит, срок жизни, права владельца, уведомления);
- `Link` — данные одной ссылки; `Config` — чтение настроек; `LinkException` — ошибки для пользователя.

Ссылки хранятся в памяти и пропадают при закрытии программы, сохраняется только UUID пользователя.
Методы `LinkService` синхронизированы, чтобы счётчик переходов не сбивался при одновременной работе
фонового потока и пользователя.

## Тестирование

```bash
mvn test
```

Тесты проверяют: уникальность ссылок у разных пользователей, лимит переходов и блокировку, удаление по сроку
жизни (час и сутки, время двигается вручную через `Clock`), уведомления, права владельца, проверку URL и лимитов,
чтение настроек.

Чтобы увидеть автоудаление вручную, поставьте в `config.properties` `link.ttl-seconds=20`, создайте ссылку
и подождите.
